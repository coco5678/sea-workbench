个人海淘记录中心 · 离线版
==========================

一个纯 HTML/CSS/JS 的静态网页应用（星露谷像素田园风），
零依赖、零构建，数据全部保存在本机浏览器里（localStorage + IndexedDB）。

功能
----
- 采购入库：记录海外商品（外币原价 ÷ 代付汇率 = 人民币成本），支持币种滑动选择、
  物流信息、商品截图。
- 售卖台账：点选「关联采购」（照片 + 名称），自动计算单品纯利润。
- 日常账本：日常生活收支，按月统计结余，与海淘成本完全独立核算。
- 物流追踪：登记泰/越/菲快递单号，按「已回国 / 未回国」分组，可记录轨迹。
- 数据管理：导出 / 导入 JSON 备份、二维码分享码、4 款主题皮肤。

使用方法
--------
方式一（最简，完全离线）：直接双击打开 index.html 即可使用。
方式二（推荐，可享受 PWA / 离线缓存）：在本目录启动一个本地静态服务器，例如：

    python3 -m http.server 8123

然后浏览器访问 http://localhost:8123

说明
----
- 本包已内置像素字体（PressStart2P）与二维码组件，断网也能完整使用。
- 数据保存在浏览器内，不会上传任何服务器。换设备请用「导出 JSON 备份」带走数据。
- 离线 / 双击打开时，PWA 与 Service Worker 不生效（不影响功能，只是没有离线缓存）。
- 建议用 Chrome / Edge 打开以获得最佳体验。

文件结构
